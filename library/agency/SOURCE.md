## 들여온 문서

파일 이름은 원본에서 분류 접두어만 뺐다(예: `testing/testing-accessibility-auditor.md` → `testing/accessibility-auditor.md`). 원문은 고치지 않았다. 같은 이름의 `.brief.md` 는 AI Squad 가 쓴 한국어 요약(일하는 방식·체크리스트·산출물 형식·판단 기준)이고, 멤버 실행 프롬프트에는 이 요약만 들어간다.

| 기반 경로 | 원본 파일 |
|---|---|
| `agency/research/synthesist` | `research/research-synthesist.md` |
| `agency/sales/proposal-strategist` | `sales/sales-proposal-strategist.md` |
| `agency/engineering/frontend-developer` | `engineering/engineering-frontend-developer.md` |
| `agency/engineering/minimal-change-engineer` | `engineering/engineering-minimal-change-engineer.md` |
| `agency/engineering/data-visualization-engineer` | `engineering/engineering-data-visualization-engineer.md` |
| `agency/testing/accessibility-auditor` | `testing/testing-accessibility-auditor.md` |
| `agency/testing/evidence-collector` | `testing/testing-evidence-collector.md` |
| `agency/marketing/seo-specialist` | `marketing/marketing-seo-specialist.md` |

더 들여올 때는 같은 방식으로 원문을 복사하고 `.brief.md` 를 쓴 뒤 이 표에 한 줄을 더한다.
